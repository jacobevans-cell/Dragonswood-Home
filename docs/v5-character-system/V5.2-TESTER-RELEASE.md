# Dragonswood V5.2 Tester Release

> Historical release note. The current tester renderer is V5.3; see
> `V5.3-SYNCHRONIZED-RENDERER-REPAIR.md` for the synchronized canvas, motion,
> shading, and equipment-mask repair.

V5.2 is restricted to the exact account `jacobicusjax@gmail.com`. Every other
student continues to resolve the legacy class and appearance system.

## Included

- Four classes, two genders, and Radiant/Shadow paths.
- Five genuinely distinct visual tiers at Levels 1, 5, 10, 15, and 20.
- Separate Idle, Walk Left, Walk Right, Attack/Heal, Hurt, Happy, and Celebrate
  animations. Celebrate no longer aliases Happy.
- Three skin tones: Light, Medium, and Deep.
- Three hair colors: Dark, Brown, and Silver.
- A three-step selection flow: gender, class/path, then skin/hair.
- Automatic live replacement anywhere that uses `DWRPG.resolveAppearance()` or
  `DWRPG.resolveV5Character()`.

## Profile fields

- `characterSystemVersion`
- `characterV5Gender`
- `characterV5Affinity`
- `characterV5ClassId`
- `characterV5SkinTone`
- `characterV5HairColor`
- `characterV5SelectedAt`

These fields are additive. The legacy `classId`, equipment, inventory, and
appearance data are not deleted or rewritten.

## Rollback

Per-account rollback sets `characterSystemVersion` to `legacy` and clears only
the V5 selection fields. The global emergency switch remains
`v5Config.enabled` in `dragonswood-rpg-v56.js`; setting it to `false` makes the
resolver ignore every V5 field immediately.

The pre-repair rollback point is commit `3542363009b38cbe4c4cc2d32dcaa862dec26ba1`
and local tag `pre-v5-art-progression-repair-3542363`.

## Build and verification

```powershell
python tools/build-v52-character-system.py --masters <master-folder> --prepared <qa-folder>
node tools/verify-v5-character-integration.mjs
python tools/verify-v52-character-quality.py <repository-root>
```

The production catalog is `assets/rpg/v5/catalog.json`. V5.2 keeps one compact
base animation set plus synchronized skin and hair mask layers. The shared
`DWRPG.renderV5Character()` browser renderer composites those animated WebPs at
runtime, providing all nine appearance combinations without duplicating thousands
of large raster animations.

## Generated-art source

The twelve non-warrior family masters were created with the built-in image
generation workflow in stylized-concept mode. Each prompt requested exactly five
left-to-right full-body tiers, the same identity/gender/path, strong equipment and
weapon escalation, clean transparent alpha, and no text, panels, shadows, white
cutout shapes, checkerboards, logos, or watermarks. The immutable source masters
are retained in the V5.2 workspace art-masters folder; the build script performs
background cleanup, tier isolation, normalization, animation, and appearance
layer generation.
