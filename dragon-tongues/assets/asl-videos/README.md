# Reviewed ASL delivery clips

Place only rights-cleared, Deaf-educator-reviewed `.webm` or `.mp4` delivery files in this directory. Add each approved clip to `data/asl-video-library.js` with `status: "ready"`, complete creator/reviewer/license metadata, and its path relative to the app root.

Do not place ASL-LEX, ASL Citizen, WLASL, How2Sign, ASLLVD, YouTube, Lifeprint, or other third-party videos here unless the exact clip has written redistribution permission compatible with standalone and hosted Dragon Tongues releases.

See `ASL-VIDEO-PRODUCTION-GUIDE.md`, `ASL-VIDEO-SHOT-LIST.csv`, and `ASL-VIDEO-RELEASE-TEMPLATE.md`.
