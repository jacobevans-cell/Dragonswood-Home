# Legal / Content Scope

This project is an original implementation of a one-button auto-running rhythm platformer.

It intentionally excludes:

- Geometry Dash logos and trademarks as in-game branding
- RobTop artwork and sprite sheets
- Official Geometry Dash level layouts or level data
- Official Geometry Dash music or sound recordings
- Decompiled or proprietary Geometry Dash source code
- Any asset requiring ownership of a Geometry Dash installation

The included SVGs, procedural graphics, level layouts, and synthesized audio were created for this package.
