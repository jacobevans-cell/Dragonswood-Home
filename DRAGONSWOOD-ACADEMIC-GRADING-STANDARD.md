# DRAGONSWOOD ACADEMIC GRADING STANDARD — V2

## Core rule
Grade the academic knowledge the student demonstrated, not whether the student guessed the exact string stored by the computer.

## Locked rules
- Ignore leading/trailing spaces unless spacing itself is assessed.
- Collapse repeated spaces.
- Ignore capitalization unless capitalization is assessed.
- Ignore harmless ending punctuation unless punctuation is assessed.
- Accept the shortest response that proves the concept.
- If the prompt already names the category, the student does not need to repeat it.
- “Which perfect tense?” accepts `past`, `present`, or `future`; longer correct forms also pass.
- Multi-word constructions such as `had reached` do not become surprise cold-typed questions.
- Equivalent mathematical representations are equivalent.
- Exact math, known choices, matching, sorting, spelling, capitalization, and punctuation use deterministic $0 grading.
- Open wording uses: deterministic check → contextual aliases → cache → paid AI rescue only if unresolved → teacher review.
- AI is rescue-only. It can rescue a false rejection; it never overturns deterministic correct work.
- Only high-confidence AI may approve.
- AI uncertainty, outage, or budget exhaustion must not count a possibly-correct answer wrong.
- Teacher review remains the final safety valve.
- Do not send student names/emails to the model when question + answer are sufficient.
- Paid calls are capped, cached, logged, and visible to the teacher.
- No cold guessing. Teach/model before requiring unfamiliar production.
