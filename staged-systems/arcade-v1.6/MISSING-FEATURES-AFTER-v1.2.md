# Missing Features After v1.2

This is the remaining feature-parity backlog after the easy v1.2 fixes. Items already implemented in v1.2 are intentionally removed from this list.

## Dragon Dash — remaining

### Good next medium upgrades
- Mini mode / size portals
- Teleport portals
- Mirror portal
- Slopes
- Moving platforms
- Rotating platforms / grouped motion
- Gravity-strength changes
- Swing mode
- Dash orbs and gravity-dash orbs
- Spider orb / spider pad
- Teleport orb

### Larger gameplay systems
- Dual mode
- Reverse direction gameplay
- Free-fly behavior
- Platformer Mode
- Jetpack/platformer-specific controls
- Force blocks

### Editor depth still missing
- Select / multiselect
- Copy / paste / duplicate
- Undo / redo
- Rotate / scale / stretch / flip
- Fine-grid placement
- Layers, groups, parent groups, and Z-order
- Per-object color / opacity / glow / animation properties
- Move / rotate / follow / stop / spawn / toggle triggers
- Alpha / pulse / color triggers
- Count / collision / touch triggers
- Camera zoom / offset / rotate / static controls
- TimeWarp / random / reverse / event / keyframe systems
- Shader and screen-effect triggers
- Custom music, song offset, SFX triggers, and particle editor

### Meta/content systems intentionally not copied yet
- Online user-created level browser
- Ratings / lists / gauntlets
- Daily / weekly featured levels
- Full Geometry Dash-style currencies, shops, chests, vaults, and quests

The last group should remain Arcade-level systems if added at all rather than becoming a second Dragonswood economy.

## Void Runner — remaining

### Biggest gameplay/visual gaps
- Variable tunnel side counts such as 4 / 6 / 8 / 10 / 12 / 16+ sides
- Different tunnel widths and lane widths
- Ramps / angled surfaces
- True 3D boxes that can become floors/walls under gravity rotation
- More handcrafted obstacle chunk types
- More dramatic tunnel shape changes and disconnected platform layouts

### Character abilities still missing
- Manual gravity-flip dragon
- Air-dash + glide dragon
- Duplicate/echo dragon mechanic
- Light-bridge / gap-building dragon mechanic

### Explore / progression gaps
- Branching Galaxy Map instead of a single Level 1 → 24 line
- Named tunnel branches with distinct mechanics
- Character encounters and short story/dialogue events
- Larger Explore campaign
- Challenge/achievement system

### Infinite Mode gaps
- Curated reusable obstacle-chunk library mixed into procedural generation
- Character-switch/continue mechanic after a failed Infinite run
- More deep-run environment phases

### Major expansion systems
- Bridge-building style puzzle campaign
- Character-specific mission campaign
- Backwards/reverse challenge mode
- Void Runner level editor / user-made tunnels

## Recommended order from here

1. Variable-sided Void Runner tunnels.
2. Dragon Dash teleport portals + mini mode.
3. Void Runner ramps and more tunnel shapes.
4. Dragon Dash slopes + moving platforms.
5. Void Runner branching Galaxy Map.
6. Dragon Dash Swing mode.
7. Only then consider the large editors/dual/platformer/3D-box systems.
