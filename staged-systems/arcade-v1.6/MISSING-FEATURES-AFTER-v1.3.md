# Missing Features After v1.3

The easy and normal/medium Void Runner backlog from the prior audit has now been implemented in the clean-room Dragonswood version. What remains is predominantly difficult, large-scope, or intentionally omitted.

## Void Runner — difficult / expansion-scale remaining work

1. **Gravity-aware freestanding 3D boxes** whose top, sides, and underside can become running surfaces independently of the tunnel shell.
2. **Duplicator-style dragon** with multiple independently simulated copies and clone collision/state.
3. **Light-bridge dragon** that creates temporary collision platforms across gaps on arbitrary gravity surfaces.
4. **Bridge-building puzzle campaign** with movable/carryable boxes and puzzle-state validation.
5. **Full Void Runner level editor** for tunnel geometry, panels, gaps, ramps, collectibles, darkness, routes, testing, validation, save/load, and sharing.
6. **Hundreds-level Run 3-scale content library.** v1.3 has 48 Explore levels plus modular Infinite content; producing 300+ deliberately authored levels is now primarily a content-production project.
7. **Full cinematic/story parity** with large dialogue trees and the original game's full cast/story structure. Dragonswood intentionally uses a lighter original story layer instead.
8. **Exact original Run 3 level layouts/assets/music.** Intentionally not included.

## Dragon Dash — still outstanding from the broader parity audit

Dragon Dash was preserved during the v1.3 Void Runner engine refactor. Remaining larger items include mini mode, teleport/mirror portals, Swing, slopes, moving/rotating platforms, dash/spider/teleport interactions, reverse/free-fly systems, Dual Mode, Platformer Mode, and the much deeper Geometry Dash trigger/editor ecosystem.

## Recommended next difficult feature

If another major Void Runner fidelity pass is desired, gravity-aware freestanding 3D boxes would add the most genuinely new traversal behavior. It should be treated as a separate physics release with rollback protection rather than bundled into a cosmetic/content pass.
