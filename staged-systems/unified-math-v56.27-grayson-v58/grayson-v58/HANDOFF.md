# Handoff

Authoritative base audited: Dragonswood `main` at `30b13bc9c8ed4f1385e3f33dba1a8c69fda1abec`.

The existing Grayson engine was v1.0 and explicitly math-game-only. This package replaces only the Grayson engine/documentation and adds or version-bumps its script tag on academic student pages. It does not edit Firestore rules, teacher portals, or the main student portal.

The context matcher intentionally re-reads visible active/current problem text for every generated challenge, so subject changes inside single-page Daily/Curriculum flows are respected.
