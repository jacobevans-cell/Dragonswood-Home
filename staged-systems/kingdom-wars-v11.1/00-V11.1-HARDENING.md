# Kingdom Wars V11.1 Hardening

This is the hardened tester-only V11 runtime. It does not enable live PvP, alter Crown semantics, rebalance the economy, or bypass the V3.3 integration gate.

## Fixed

- Tester access is allowlist/role based. A non-school email plus a student document is no longer sufficient.
- Old and partial saves migrate missing health rows as fully healthy while preserving recorded damage and destruction.
- The local player save has a V11.1 key and explicit `saveVersion`; the previous test key is migrated once.
- Ranked loot transfers no more than the defender actually owns and cannot create resources.
- Returned ranked-result state is deep copied rather than nested aliases.
- Palette result/image caches are bounded and canvases are reused.
- Unknown styles and hostile custom palette values fall back to safe values.
- Match tickets expire and scouting varies by defender.
- Simulated opponents accrue capped production between sessions.
- Negative and non-finite saved resources normalize safely.
- Test damage ignores already-destroyed buildings.
- UI actions have shared in-flight protection before any async backend migration.
- Repair-all uses cheapest-first ordering and reports skipped repairs and missing resources.
- Refresh/highlight timers are tracked instead of stacking; battle audio reuses one `AudioContext`.
- HP animations stop for reduced motion and pause when the page is hidden.
- Auth restoration waits up to 12 seconds and reports timeout separately from denial.

## Intentionally deferred

- Full scene diff-rendering requires a dedicated visual regression environment.
- Pre-baking all palette variants is an asset-pipeline milestone.
- Archive-only masters remain in the source package but should not be copied into the deployed web tree.
- Crown changes remain ladder-point semantics, not conserved currency.
- V12 server-authoritative PvP, shields, revenge, and repeat-target policy remain out of scope.

## Verify

```bash
bash tools/verify-v11.1-hardening.sh
```

The gate runs syntax checks, all eight original V9/V10/V11 suites, the 902-file live asset routing check, and the new adversarial core/persistence/access/runtime tests.
